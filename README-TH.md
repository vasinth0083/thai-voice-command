# thai-voice-command (ภาษาไทย)

ไลบรารีสำหรับสั่งงานด้วยเสียงภาษาไทย ใช้ได้กับระบบแปลงเสียงเป็นข้อความ (ASR) ตัวไหนก็ได้

## ทำอะไรได้
1. **จับคำปลุก** แม้ ASR จะสะกดผิด เช่น จาร์วิส / จาวิส / จาวิทย์
2. **จับคู่คำสั่ง** โดยไม่สนช่องว่างและคำลงท้าย (ครับ, ค่ะ)
3. **ดึงข้อความต่อท้าย** เช่น "ค้นหา แมว" ได้ค่า "แมว"
4. **เดาคำที่ได้ยินผิดอย่างปลอดภัย** ถ้าไม่มั่นใจจะไม่ทำอะไรเลย
5. **ตัดเสียงจากไมค์เป็นประโยค** (VAD) เขียนด้วย Python ล้วน

## ทำไมถึงปลอดภัย
คำสั่งแบบ fuzzy จะผ่านได้ต้องเข้าเงื่อนไข 2 ข้อ
- คะแนนความคล้ายต้องไม่ต่ำกว่า 0.78
- คะแนนต้องทิ้งห่างคำสั่งอันดับสองอย่างน้อย 0.065

ตัวอย่าง: "เปิดโน๊ตแพด" ได้คะแนนใกล้คำว่า "เปิด" 0.909 และใกล้คำว่า "ปิด" 0.857
สองค่านี้ห่างกันแค่ 0.052 ระบบจึงไม่ทำอะไร เพราะการไม่ทำอะไรปลอดภัยกว่าการเปิด/ปิดโปรแกรมผิด
